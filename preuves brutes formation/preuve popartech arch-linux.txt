VERIFIER SI LA PARTITION DE BOOT EST AU MINIMUM DE 500 GO!!!!!!
si ce n'est pas le cas:
démarrer sur une clé Windows bootable
aller dans dépannage (SURTOUT PAS INSTALLER UN NOUVEAU WINDOWS)
aller dans le CMD
avoir prévue de la place avant…
diskpart
select disk 0 (le disque ou est Windows de base ou l'os…)
list part
create partition efi size=1024 (suivant la taille voulue)
format fs=fat32 quick label=EFI
assign letter=S
exit
dir C:\Windows
bcdboot C:\Windows /s S: /f UEFI
exit
étteindre l'ordinateur, enlever la clé bootable Windows
aller dans le bios, si la partition de boot apparait dans le boot du bios c'est bon
suprimer la partition de boot de trop
dans un cmd admin (Windows normal)
diskpart
sel disk 0
list part
sel part X (la partition boot en trop, celle qu'on ne veux plus utiliser)
delete partition override
exit
si la supression c'est faite sans problème c'est bon sinon il faut ce renseigner sur internet car chaque cas peut être différents d'autres.
